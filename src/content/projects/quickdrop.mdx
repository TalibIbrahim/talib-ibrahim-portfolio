## Context

QuickDrop is privacy-first file sharing. Files move between devices peer to peer, and nothing is meant to stick around afterwards.

## What I built

- Peer-to-peer transfer using WebRTC, with a P2P architecture that uses TURN/open relay servers.
- Strict auto-deletion logic to protect user privacy and security.
- Lossless uploads.
- QR code device pairing.

## Stack notes

The front end is React.js. Socket.IO and PeerJS handle the real-time and peer-to-peer side. MongoDB and Cloudinary round out the stack.
