## Context

GitChat is an AI codebase assistant for interactive repository analysis. Point it at a GitHub repository and ask questions about the code.

## What I built

- A RAG pipeline built on semantic retrieval and document chunking.
- MongoDB Atlas Vector Search for semantic retrieval of GitHub repositories.
- Streaming of AI reasoning from local LLMs.

## Stack notes

Built with Next.js. The Vercel AI SDK and LangChain interface with local Ollama models, and MongoDB stores the vectors for retrieval.
