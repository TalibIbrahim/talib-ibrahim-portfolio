## Context

LedgerERP is an inventory and ledger desktop app I built through Radix Systems. It runs on Windows and macOS.

<Facts />

## What I built

- Purchase and sales vouchers with drafts, search, keyboard shortcuts and stock validation.
- Customer accounts, a credit ledger, payment tracking and monthly sales reports.
- Local storage with cloud sync to MongoDB, plus Trash and backups.

## Stack notes

Electron, React and TypeScript with Vite and Tailwind CSS. Data lives in a local NeDB store and syncs to MongoDB. A GitHub Actions workflow builds the Windows installer and the macOS DMG and publishes the auto-updates.
